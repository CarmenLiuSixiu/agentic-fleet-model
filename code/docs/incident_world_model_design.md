# 事故信息增强的世界模型 + 车队智能体闭环 设计 v0.1 (2026-10-26)

## 1. 问题
世界模型现在漏掉约 44% 的拥堵样本(速度 < 70 km/h), 很多应是事故等偶发事件。问题:
- Q1 只用"决策时刻已经报告"的事故信息, 能否补上漏掉的拥堵、改善 30–60 分钟预测?
- Q2 预测改善后, 车队智能体的决策是否更好、在模型出错时是否更稳(策略排序是否不变)?

## 2. 相关工作与定位(已核实)
| 工作 | 做了什么 | 和我们的差别 |
| --- | --- | --- |
| Event Traffic Forecasting with Sparse Multimodal Data, ACM MM 2024 | 事件文本 + 交通时序融合(细节未读到) | 城市活动事件, 无决策 |
| MTP, AAAI 2026 (Xiang et al.) | 数值/图像/文本三视图, 图像与文本由交通数据生成 | 无外部信息 |
| 事故报告驱动的拥堵传播预测, UCSD/DTU 2023 (SIGSPATIAL workshop) | 融合实时流量与事故报告, 优于不用事故的图模型 | 无"报告延迟"约束, 无物理模型, 无决策 |
| Incident-Guided Spatiotemporal Traffic Forecasting, arXiv 2602.02528 | 事故引导的时空图预测 | 同上 |
| Flow / mixed-autonomy RL benchmarks, CoRL 2018 (Vinitsky et al.) | 自动驾驶与人驾混合交通控制基准 | 无检测器标定世界模型, 无事故 |
"加事故能改进预测"本身不新。我们的贡献只放在三点: (1) 决策时可得(as-of)约束, 报告前的事故不可用; (2) 事故信息只进背景修正, 干预的反事实由物理模型承担; (3) 按决策价值评估(车队策略与稳健性)。

## 3. 数据
- PeMS 2026-04/05/06, 53 个可用工作日, 36 训 / 17 测(每三天一测, 与 calibrate_daily_2026 一致)。
- CHP 事故(District 4, 2026-04–06, 用户下载): 每条取位置(路线、里程)、报告时刻、结束时刻、类型。
- as-of 规则: 决策时刻 t 只能用报告时刻 ≤ t 的事故, 且只知道到 t 为止的状态; "事后"版本额外知道完整起止与位置, 作上限。

## 4. 模型
| 编号 | 模型 |
| --- | --- |
| M0 | 物理 CTM + MHE(现有, 参数 wm_params_2026i 或逐日 τ6) |
| M1 | M0 + 残差网络, 输入: M0 的 15/30/60 min 预测、最近 30 min 残差、时段、路线 |
| M2 | M1 + 已报告事故特征(距检测器的上下游距离、已持续时间、类型、车道) |
| M2-事后 | M1 + 完整事故信息(上限) |
残差网络: 小 MLP 或单层 GRU, 按检测器共享权重; 输出预测修正量; 训练只用训练日; 早停用训练日内按天留出。

## 5. 评估(预注册)
- 指标: 30/60 min 路线行程时间 MAE、检测器速度 MAE、漏报拥堵召回、拥堵开始时间误差; 全部测试日与事故日分开报告; 按天配对 bootstrap。
- 门槛 G1: M1 优于 M0(60 min 路线 TT, 90% 区间不含 0), 否则残差不进闭环。
- 门槛 G2: M2 优于 M1, 只看事故日, 90% 区间不含 0; 不过 → 论文不主打多模态, 照实报告。
- 量化报告延迟的代价: (M2-事后 − M2) / (M2-事后 − M1)。

## 6. 接入闭环
- 管理方用 M2 预测背景路况; 干预效应由物理部分推演; 残差强度 λ ∈ {0, 0.5, 1} 做敏感性。
- 检验: F0–F3 车队策略排序在 λ 与真值(CTM/METANET)之间是否稳定。
- A4 回退: 最近 30 min 预测误差或残差超过阈值时, 由 F2 降到 F3(只谈空车)。
